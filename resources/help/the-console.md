# The console

The console is the first page of every server. It shows the live output of the game, the server's address, CPU, memory and disk use, and the power buttons.

## Sending commands

Type a command in the box under the output and press **Enter**.

- **↑ and ↓** step through the commands you sent before. The console remembers the last 32 commands for each server in this browser.
- **Tab** completes the game's common commands. While you type, suggestions show above the box; ↑ and ↓ pick one and **Esc** hides them.

The box says **Waiting for the connection…** until the console is connected to the server.

## Searching the log

Use **Search the log** above the output to highlight every line that matches what you type.

- The **filter** button next to it shows only the matching lines.
- **Pause** freezes the output so you can read it; new lines keep arriving in the background and **Resume** catches up.
- **Copy all** copies the output, and **Download log** saves it as a file.
- Scrolled up? A button jumps you back to the newest output.

## Power buttons

- **Start** starts the server.
- **Restart** stops it cleanly and starts it again.
- **Stop** shuts it down cleanly, saving the world first.
- **Kill** ends the process at once, without saving. It asks first, because it can corrupt world or plugin data. Use it only when **Stop** does not work.

The badge next to the buttons shows the state: Online, Starting, Stopping or Offline.

## When something goes wrong

If the server crashes or fails to start, the console offers to let the AI crash doctor check it. See [The AI assistant and crash doctor](/help/ai-assistant-and-crash-doctor) and [Troubleshooting](/help/troubleshooting).
