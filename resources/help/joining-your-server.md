# Joining your server

Every MonoForge server gets a public **playit.gg** address, such as `example.joinmc.link`. Players connect to it straight away: there is no port forwarding and no IP address to hand out.

## Where to find the address

- On the **dashboard**, under the server's name.
- On the server's **console**, in the **Address · playit.gg** box. Click it to copy the address.
- On the server's **Network** page, as **Public address (playit.gg)**. Click it to copy.

## "Address pending"

A new server needs a moment for its playit.gg tunnel to be set up. Until then you see **Address pending** where the address goes. The address appears by itself as soon as the tunnel is ready, usually within a few minutes. The ports listed on the Network page belong to the node and are not reachable from outside, so wait for the playit.gg address rather than using them.

If a server shows "Address pending" for a long time, [open a support ticket](/help/support-tickets) and we will look at its tunnel.

## How friends join

Start the server from its console, then share the address.

- **Minecraft (Java):** open **Multiplayer**, choose **Add Server**, paste the address as the server address and join.
- **Terraria:** choose **Multiplayer**, then **Join via IP**. If the address ends in a colon and a number (such as `:12345`), enter the part before the colon as the IP and the number as the port.

Friends do not need a MonoForge account to play. To let someone help you *manage* the server, see [Friends and sharing access](/help/friends-and-sharing-access).

## Share a page instead

Turn on your server's [public page](/help/public-server-page) for a link at `/s/your-name` that shows the address, whether the server is online and how many people are playing.
