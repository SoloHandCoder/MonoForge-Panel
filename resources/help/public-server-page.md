# The public server page

Every server can have a public page at an address such as `/s/skyblock` on this panel. It shows your server's name, banner, description, whether it is online, how many players are on, the join address and its votes. Anyone can open it without an account, and links to it show a preview card on Discord.

## Setting it up

Open the server and go to **Public page**.

- **Address:** 3 to 32 lowercase letters, numbers and hyphens. Changing it breaks links you already shared.
- **Published:** turn it on to make the page live; turn it off to hide it again.
- **Hide from search engines:** asks Google and others not to list the page. Links still work.
- **Banner image:** an image of up to 1 MB. Without one, the page uses your colour.
- **Description and colour:** the description can use markdown, such as **bold**, *italic*, links, lists and headings.

The page only ever shows the server's [playit.gg address](/help/joining-your-server). Until the server has one, visitors are asked to contact you to join.

## Votes

Visitors who like your server can vote for it once a day. The page shows the total.

## Wake

If your server uses [auto-sleep](/help/renewals-and-unpaid-servers), you can turn on **Let visitors wake the server**. While the server sleeps, the page then shows a wake button, so players can start it without asking you. It can be used a few times an hour, and every wake means paying for the time the server runs.

Setting up the page needs the public page permission on the server; owners have it.
